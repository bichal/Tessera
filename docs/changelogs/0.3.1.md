# Changelog: Tessera v0.3.1 (1.21 – 26.3)

This update fixes a grey bar that appeared next to the crosshair.

---

## Key Features & Changes

* **Crosshair Fixed**: The crosshair no longer shows a grey bar beside it. Tessera now leaves the small interface texture atlas alone, so every menu, hotbar and HUD sprite is drawn exactly as in vanilla. The saving lost is about a megabyte of video memory.
* **Same On Every Version**: The fix applies to every supported Minecraft version, 1.21 – 1.21.11 and 26.1 – 26.3.
