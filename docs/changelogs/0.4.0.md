# Changelog: Tessera v0.4.0 (1.21 – 26.3)

**Tessera** now runs on Fabric too, on Apple Silicon and Android GPUs, and splits the game's texture atlases in two: the static ones are compressed as small as their content allows, and the animated ones are left exactly as vanilla draws them, so it works side by side with Kerria.

---

## Key Features & Changes

* **Static and Animated Atlases, Split**: Atlases without animated textures are compressed; atlases with any (such as the block atlas, with water, lava and fire) stay uncompressed, so animations look and run exactly as in vanilla. Press F3 to see both: the video memory saved on the static atlases, and what the animated ones take.
* **Works with Kerria**: Kerria speeds up animated textures, Tessera shrinks the static ones. Each works on its own atlases, so you can use both.
* **Smaller Cut-out Textures**: Atlases without mipmaps whose textures are only fully see-through or fully solid (common in mods and resource packs) can now take half the video memory they did, with transparency kept exact. Tessera checks the result first: if an atlas would look worse, it keeps the larger format for it.
* **Fabric**: Tessera now runs on Fabric (with Fabric API) for every supported Minecraft version, with its settings in Mod Menu.
* **Apple Silicon and Android**: Uses ASTC, the format ARM GPUs take. macOS also takes the PC format for solid textures.
* **Faster Start-up**: An atlas that hasn't changed since the last launch is loaded from the disk cache in one go, and the cache takes less disk space.
* **Safer on Unusual Drivers**: Tessera checks that the graphics driver accepted each compressed atlas, and leaves it as vanilla if not.
* **Requirements**: Needs **Celeris** 0.3.1.1 or newer.
