# Tessera wiki

Tessera makes Minecraft use less video memory. Start here.

- [Settings](Settings.md): options and where to change them
- [Memory savings](Memory-savings.md): what the numbers mean
- [Requirements and files](Requirements-and-files.md): versions, Java, JVM flags, which jar to take
- [How it works](How-it-works.md): what happens to the textures
- [Developers](Developers.md): events and the developer guide

Tessera needs [Celeris](https://github.com/bichal/Celeris) in the same `mods` folder.

Found a bug? [Open an issue](https://github.com/bichal/Tessera/issues).
